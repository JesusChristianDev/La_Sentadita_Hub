# docs/

Esta carpeta ya no es la fuente de verdad documental del proyecto.

## Estado actual

- `../canon/` es el canon oficial activo.
- `../archive/` guarda planes y paquetes historicos de referencia.
- `legacy/` guarda especificaciones y notas historicas.
- `backups/` y `lighthouse/` guardan artefactos tecnicos.

## Regla de uso

- No tomes decisiones nuevas usando `docs/legacy/` sin contrastarlas con `canon/`.
- Si hay contradiccion, prevalece `canon/`.
- Los enlaces internos de `legacy/` pueden estar desactualizados porque ese material se conserva solo como archivo.
