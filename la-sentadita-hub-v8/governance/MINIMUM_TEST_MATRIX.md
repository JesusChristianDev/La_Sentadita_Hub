
# Minimum Test Matrix

Antes de considerar un módulo terminado deben existir tests para:

AUTHZ
- permisos por rol
- restricciones de visibilidad

SCHEDULING
- no solapamientos
- un restaurante por día

TASKS
- tarea siempre con responsable
- estados válidos

PROCEDURES
- no autoaprobación
- efectos sobre scheduling

DOCUMENTS
- ownership correcto
- visibilidad correcta
